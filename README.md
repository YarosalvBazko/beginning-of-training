# Beginning of Training 🚀

### Repository for learning PHP basics. Examples of arithmetic, strings, and conditions.

## 📁 Files
```bash
Beginning-of-training/
├── functions.php # Math
├── index.php # Strings
├── lines.php # (coming soon)
└── conditional_operators.php # (coming soon)
```


## 📄 Contents

### `functions.php` - Math
- Operations: `+`, `-`, `*`, `/`, `%`
- Assignment: `+=`, `-=`, `*=`, `/=`
- Increment/Decrement: `++`, `--`
- Constants: `M_PI`, `M_E`
- Functions: `abs()`, `ceil()`, `floor()`, `round()`, `mt_rand()`, `max()`, `min()`

### `index.php` - Strings
- Quotes: `" "` vs `' '`
- Concatenation: `.`
- Functions: `strlen()`, `trim()`, `strtoupper()`
- Hashing: `md5()`

## 🛠️ Run

```bash
php -S localhost:8000
```

## Beginning of Training 🚀

### Репозиторий для изучения основ PHP. Примеры работы с арифметикой, строками и условиями.
```bash
Beginning-of-training/
├── functions.php              # Математика
├── index.php                  # Строки
├── lines.php                  # (скоро)
└── conditional_operators.php  # (скоро)
```

### functions.php - Математика
  - Операции: +, -, *, /, %
  - Присваивание: +=, -=, *=, /=
  - Инкремент/декремент: ++, --
  - Константы: M_PI, M_E
  - Функции: abs(), ceil(), floor(), round(), mt_rand(), max(), min()

### index.php - Строки
  - Кавычки: " " vs ' '
  - Конкатенация: .
  - Функции: strlen(), trim(), strtoupper()
  - Хеши: md5()
